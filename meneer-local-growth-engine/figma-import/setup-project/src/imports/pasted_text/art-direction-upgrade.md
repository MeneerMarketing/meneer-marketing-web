# SECTION ART DIRECTION UPGRADE

The current website foundation is good.

Do NOT redesign the complete website from scratch.

Keep the existing:

* brand system
* navigation
* typography family
* color palette
* hero direction
* page structure
* existing content hierarchy

I now want you to significantly upgrade the **visual art direction of all content sections below the hero**.

Use the supplied reference screenshot as the main benchmark for this part of the design.

The goal is to create sections that feel:

**editorial + branded + art-directed + premium + modular**

rather than:

**generic cards placed on a white page.**

---

# 1. CORE VISUAL PRINCIPLE

Every major section should feel like it has been deliberately composed by a high-end editorial design studio.

The strongest visual ingredients should be:

* premium photography
* brand-colored image treatments
* large tonal surfaces
* asymmetric modular layouts
* different card sizes
* elegant whitespace
* minimal typography
* subtle micro-labels
* oversized rounded containers
* very restrained decorative graphics
* text integrated into imagery
* strong color hierarchy

Avoid simply creating:

3 equal white cards
4 equal feature cards
image + text
image + text
image + text

That quickly looks like a generic website template.

Instead, each section should have its own **visual composition** while still clearly belonging to the same design system.

---

# 2. USE BRAND COLOR AS AN ART-DIRECTION TOOL

The brand color must become part of the photography and layout system.

Do not only use the primary color for buttons.

Use the brand palette throughout sections in sophisticated ways.

Create tonal levels such as:

Primary Dark
Primary
Primary Medium
Primary Soft
Primary Mist
Primary Very Light

For example, if the brand color is green:

Dark Green
`#174F36`

Primary Green
`#26734A`

Medium Green
`#629A76`

Soft Green
`#CBE7C1`

Mist Green
`#EEF6EA`

Near White
`#F8FAF6`

If the template uses another brand color later, derive the same tonal system from that color.

The important principle:

**one primary brand hue expressed across multiple levels of saturation and brightness.**

This creates a much richer identity than simply placing one colored button on a white website.

---

# 3. BRANDED PHOTOGRAPHIC OVERLAYS

This is extremely important.

For selected photography blocks, apply a sophisticated color treatment derived from the brand color.

For example:

TOP:
photography remains natural

BOTTOM:
gradually transition into a deep version of the brand color

The transition should feel cinematic and photographic, not like a visible CSS overlay.

Example direction:

transparent
→
rgba(25, 80, 55, 0.20)
→
rgba(20, 70, 45, 0.85)

The bottom 30–45% of the photograph can subtly merge into the brand color.

This allows white typography to sit directly inside the image.

The result should feel like a **magazine campaign image**, not a normal card with text pasted over it.

---

# 4. TEXT INSIDE PHOTOGRAPHY

Use editorial copy directly inside selected images.

Position:

bottom-left

with generous internal spacing.

For example:

“Vanaf het eerste gesprek
voelde ik me gehoord.”

or:

“Rust in je huid.
Rust in je hoofd.”

or:

“Geen standaard behandeling.
Wel een persoonlijk plan.”

Typography should be:

large enough to feel intentional

but not gigantic.

Desktop:

26–38px depending on image size.

Use:

white / warm white text.

Keep the quote or statement concise.

Maximum approximately:

2–4 lines.

Do NOT overlay paragraphs.

---

# 7. CINEMATIC CROPPING

Photography should often use intentionally unusual crops.

Examples:

only clinician hands during treatment

partial profile of patient

close-up of skincare equipment

architectural close-up

close-up of product or instrument

Do NOT always center the subject.

Allow subjects to sit:

far left
upper corner
partially outside frame

This makes photography feel art-directed.

# 9. LARGE COLORED SECTION CANVASES

Some sections should sit on one large pale branded canvas.

For example:

Think:

---

# 10. MODULAR ASYMMETRIC GRIDS

Use intentionally different module sizes.

For example:

45% width
30% width

50% functional panel

or:

60% photography

Avoid:

33% / 33% / 33%

everywhere.

A good composition could be:

[ small text card ] [ large brand feature card ] [ medium white card ]

The differences in size should create hierarchy.

---

# 11. CARD HEIGHTS

Not every card should have the same amount of content.

Some modules may only contain:

The system should feel curated rather than mechanically uniform.

# 14. ABSTRACT BRAND SHAPES

Inside some dark or medium-colored cards, introduce extremely subtle abstract shapes derived from the brand.

For example:

curved organic shapes

cropped circles

soft arcs

abstract medical contour

large translucent forms

Rules:

* same color family
* low contrast
* partially cropped
* never decorative clipart
* never random blobs

Think of these as:

**brand graphics**, not illustrations.

They should appear as if they were part of a professional identity system.
