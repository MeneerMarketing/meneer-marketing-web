# DIBA Clinics — Copy Style Intake Form

**Doel:** één keer invullen, daarna sitebreed toepassen op alle nieuwe en herschreven teksten.  
**Wie vult in:** Okan (merk & strategie) + Rojda (medische toets) + eventueel copywriter.  
**Invultijd:** 30–45 minuten.  
**Versie:** ___________ · **Datum:** ___________

> Aanvulling op [DIBA-RULES.md](DIBA-RULES.md) §10. Die regels blijven leidend; dit formulier maakt de stem concreet invulbaar.

---

## Hoe je dit formulier gebruikt

- Vul elk veld in. Laat niets leeg: schrijf `n.v.t.` als het niet van toepassing is.
- Bij twijfel: kies de optie die het dichtst bij de behandelstoel staat, niet bij wat "mooi klinkt op papier".
- Markeer medische passages met `[ROJDA-CHECK]` tot Rojda ze heeft goedgekeurd.
- Na invullen: dit document is de referentie bij elke nieuwe pagina, e-mail of advertentietekst.

**De drie toetsen (altijd toepassen na het schrijven):**

| Toets | Vraag | ✓ / ✗ |
|---|---|---|
| Stoeltoets | Zou een Diba-behandelaar dit zo zeggen in de stoel? | |
| Influencer-toets | Kan dit van een influencerkliniek zijn? (dan fout) | |
| Duimtoets | Leest en werkt dit éénhandig op 380px? | |
